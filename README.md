HW1_ChipChat

Includes initial prompt-based interactions and outputs related to chip design concepts.

Serves as a baseline for understanding model behavior.

Builds upon Example A with additional prompt variations and test cases.

Used to further evaluate consistency and relevance.

3️⃣ chipchat_extension.ipynb

Contains extended experiments beyond the base requirements.

Investigates more advanced or exploratory chip-design queries.

Aims to analyze deeper capabilities and limitations of the model.
